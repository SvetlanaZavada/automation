# 🛒 Проект для автоматического тестирования интернет-магазина

Автотесты для проверки работы интернет-магазина. Проект помогает автоматически проверять, 
что всё работает правильно: авторизация, добавление товаров в корзину и оформление заказа.

## 🛠 Технологии

Проект написан с использованием:

- **Python** — язык программирования
- **Selenium** — для управления браузером
- **Pytest** — для запуска тестов
- **Allure** — для создания красивых отчетов

## 🔧 Установка

### 1. Скачай проект

Скачай проект на свой компьютер любым удобным способом.

### 2. Установи Python

Если Python ещё не установлен, скачай его с официального сайта:  
https://www.python.org/downloads/

### 3. Установи библиотеки

Открой командную строку (или терминал) в папке с проектом и выполни команду:

```bash
pip install -r requirements.txt
```

Эта команда установит все нужные библиотеки, которые перечислены в файле `requirements.txt`.

## 🚀 Запуск тестов

### Запуск тестов с сохранением результатов для Allure

```bash
pytest --alluredir=allure-results
```

**Что произойдет:**
- Запустятся все тесты
- Результаты сохранятся в папку `allure-results`

### Запуск конкретного теста

```bash
pytest tests/test_shop.py
```

### Запуск тестов с подробным выводом

```bash
pytest -v
```

## 📊 Просмотр отчета Allure

### 1. Установи Allure (если не установлен)

**Если у тебя Windows:**
```bash
choco install allure
```

**Если у тебя MacOS:**
```bash
brew install allure
```

**Если у тебя Linux:**
```bash
sudo apt-add-repository ppa:qameta/allure
sudo apt-get update
sudo apt-get install allure
```

### 2. Посмотри отчет

После того как тесты запущены и результаты сохранены, выполни команду:

```bash
allure serve allure-results
```

**Что произойдет:**
- Allure создаст красивый отчет
- Отчет автоматически откроется в браузере

Ты увидишь:
- ✅ Какие тесты прошли успешно
- ❌ Какие тесты упали (если такие есть)
- ⏱️ Сколько времени выполнялся каждый тест
- 📝 Детальные шаги каждого теста
- 📸 Скриншоты (если они есть)

## ❗ Возможные проблемы и их решение

### Ошибка "WebDriver not found"

**Проблема:** Нет драйвера для браузера.

**Решение:** Установи драйвер для своего браузера:
- **Chrome:** https://chromedriver.chromium.org/
- **Firefox:** https://github.com/mozilla/geckodriver/releases

### Ошибка "ModuleNotFoundError"

**Проблема:** Не установлены библиотеки.

**Решение:** Установи их командой:
```bash
pip install -r requirements.txt
```

### Ошибка "allure: command not found"

**Проблема:** Allure не установлен.

**Решение:** Установи Allure по инструкции выше.
